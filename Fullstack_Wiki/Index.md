一段前端代码从“写出来”，到“被 JS 引擎执行”，再到“通过网络传输数据”，最后“由框架渲染成界面”，整个过程是怎么运作的。

**知识节点**

- JavaScript 基础语义：var / let / const、作用域、变量提升、暂时性死区、执行上下文。
- 异步运行机制：Event Loop、宏任务、微任务、Promise、async/await。
- 闭包与函数式技巧：闭包、柯里化、偏函数。
- 模块化：CommonJS、ES Module、动态导入、live bindings。
- 工程化：打包、Tree Shaking、代码分割、CI/CD。
- 网络与协议：LAN/WAN、DHCP、HTTP/1.1、HTTP/2、HTTP/3。
- 前后端通信：Content-Type、表单提交、JSON、FormData、Express 中间件。
- 框架实践：React 的声明式渲染、Vue 的组件通信与 TodoList 实战。
- 辅助能力：AI 辅助学习、STAR 表达法。
